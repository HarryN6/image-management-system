# image-management-system
A Java based image management system developed as the individual project for my Object-Oriented Programming module at Queen's University Belfast (QUB) during the 2025-2026 academic year.

## Overview
The project was developed using object-oriented programming principles and Java collections.

Two versions of the application are included:
* QUBImages - the standard console-based version.
* ConsoleQUBImages - a version which uses ImageIcon to display images and the compiled Console class provided by QUB for the assessment.

## Features
### Image Management
Images are represented by an ImageRecord and are managed by an ImageManager.

### Searching
The application allows images to be searched by ID, Title, Description, Date, or Genre/ImageType

### Album Navigation
Search results and the complete image collection can be displayed as an ImageAlbum. The album sorts Images by date and allows the user to navigate through the collection.

## How to Run
1. Clone the repository
2. Open the project in a suitable Java IDE
3. Ensure the Images directory is located inside the src directory
4. Ensure the provided Console JAR file has been added to the projects build path
5. Run either QUBImages or ConsoleQUBImages.
